## 🚀 Flagship Engineered Projects

### 1. 🌾 [AgriResilience-AI](https://github.com/prakruthidevanga/AgriResilience-AI)
**Multimodal Climate Risk Simulation & Crop Genomic Adaptation Prototype**  
- Developed an interactive climate resilience full-stack system linking environmental stress scenarios (heat waves, drought periods, soil salinity) to crop risk estimates, yield-loss projections, and financial impact.
- Incorporates a trained **Random Forest classification model** for crop suitability analysis and deterministic **Excess Green Index (ExG)** canopy vegetation segmentation.
- **Technologies:** Python, Flask, React.js, Scikit-learn, MongoDB, Chart.js.

[![View Repository](https://img.shields.io/badge/CODEBASE-1E293B?style=for-the-badge&logo=github&logoColor=white)](https://github.com/prakruthidevanga/AgriResilience-AI)

### 2. 🚜 [Agri-Bridge (AgroSmart)](https://github.com/prakruthidevanga/Agri-Bridge)
**AI-Enabled Multilingual Circular Economy Agricultural Platform**  
- Mobile-first P2P marketplace connecting farmers directly with industrial buyers to trade crop residue, mitigating seasonal stubble burning while calculating farmer revenue and CO₂ offsets.
- Integrated voice navigation and real-time voice assistance across **6 regional Indian languages** via the Web Speech API.
- **Technologies:** React.js, Vite, Web Speech API, Tailwind CSS, Netlify.

[![View Repository](https://img.shields.io/badge/CODEBASE-1E293B?style=for-the-badge&logo=github&logoColor=white)](https://github.com/prakruthidevanga/Agri-Bridge)

### 3. 🤖 [Smart Inventory Planning Agent (Agentic AI)](https://github.com/prakruthidevanga/Agentic_AI_Projects)
**Autonomous Multi-Agent Restocking System with Local LLM Reasoning**  
- Designed an autonomous multi-agent planner (Inventory Monitor, Replenishment Planner, Executor Agent) for smallholder retail operations.
- Orchestrates local LLMs via Ollama to evaluate stock velocity, safety buffers, and demand forecasts to generate human-readable restocking schedules.
- **Technologies:** Python, Flask, SQLite, Ollama LLM, Multi-Agent Architecture.

[![View Repository](https://img.shields.io/badge/CODEBASE-1E293B?style=for-the-badge&logo=github&logoColor=white)](https://github.com/prakruthidevanga/Agentic_AI_Projects)

### 4. 🔍 [CodeLens AI — Local Repository Intelligence](https://github.com/prakruthidevanga/GitHub-Repo-Explainer)
**AI-Powered Local Codebase Intelligence & Dependency Explainer**  
- Accepts public GitHub repository URLs, clones codebases via GitPython, extracts abstract syntax trees (ASTs), parses Jupyter notebook cells, and interfaces with local LLMs (Ollama) to produce comprehensive technical briefings.
- Engineered with strict token budgeting and code chunking to eliminate context-window overflow.
- **Technologies:** Python, FastAPI, Streamlit, GitPython, Ollama LLM.

[![View Repository](https://img.shields.io/badge/CODEBASE-1E293B?style=for-the-badge&logo=github&logoColor=white)](https://github.com/prakruthidevanga/GitHub-Repo-Explainer)
