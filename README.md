## 🚀 Featured Projects

*A selection of projects that reflect my learning, experimentation, and practical development experience.*

### 1. 🌾 AgriResilience-AI — GenAI & Climate Risk Simulation
An interactive full-stack climate resilience prototype combining environmental stress simulation (heat, drought, salinity), Random Forest crop suitability classification, and visual vegetation canopy segmentation.

**Technologies:** Python • Flask • React.js • Scikit-learn • MongoDB • Chart.js

- Integrates a trained Random Forest model predicting crop viability under variable climatic inputs.
- Computes vegetation stress using Excess Green Index (ExG) segmentation.
- Illustrates economic yield-loss projections and climate adaptation strategies.

[![GitHub](https://img.shields.io/badge/VIEW_SOURCE-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/prakruthidevanga/AgriResilience-AI)

### 2. 🚜 Agri-Bridge (AgroSmart) — Circular Economy Agriculture Platform
An AI-enabled multilingual circular economy platform designed to eliminate crop residue burning by connecting smallholder farmers with industrial buyers for agricultural biomass.

**Technologies:** React.js • Vite • Web Speech API • Tailwind CSS • Netlify

- Multi-language voice navigation and voice-assisted chatbot across 6 regional Indian languages via Web Speech API.
- Automated profit estimation and CO₂ offset calculator per biomass listing.
- Interactive carbon credit rewards system encouraging sustainable agricultural practices.

[![GitHub](https://img.shields.io/badge/VIEW_SOURCE-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/prakruthidevanga/Agri-Bridge)

### 3. 🤖 Smart Inventory Planning Agent (Agentic AI)
An autonomous multi-agent planning workflow for smallholder retail operations leveraging local LLM reasoning to generate intelligent stock replenishment schedules.

**Technologies:** Python • Flask • SQLite • Ollama LLM • Multi-Agent Design

- Implements an Agentic AI Planner architecture (Inventory Monitor, Replenishment Planner, Executor Agent).
- Connects local LLMs via Ollama to reason over stock velocity, lead times, and reorder points.
- Delivers human-readable restocking proposals through a clean web dashboard.

[![GitHub](https://img.shields.io/badge/VIEW_SOURCE-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/prakruthidevanga/Agentic_AI_Projects)

### 4. 🔍 CodeLens AI — Local GitHub Repository Intelligence
A developer-focused GenAI application that accepts any public GitHub repository URL, clones the codebase, parses abstract syntax trees, and produces structured technical briefings using local LLMs.

**Technologies:** Python • FastAPI • Streamlit • GitPython • Ollama LLM

- Clones and inspects repositories locally with GitPython, analyzing dependencies, source files, and Jupyter notebooks.
- Employs token-budgeting and code distillation to prevent context-window overflow.
- Generates architecture overviews, dependency trees, and implementation walkthroughs.

[![GitHub](https://img.shields.io/badge/VIEW_SOURCE-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/prakruthidevanga/GitHub-Repo-Explainer)
